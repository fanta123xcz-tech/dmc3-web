# AGENTS.md

## Proyecto
Sitio web fan de Devil May Cry 3, de una sola página con varias secciones.

## Reglas
- Usa únicamente HTML5, CSS3 y JavaScript vanilla. No uses frameworks ni build tools.
- Estructura de archivos: `index.html`, `css/styles.css`, `js/main.js`, `img/`.
- Usa HTML semántico (header, nav, main, section, footer).
- Diseño mobile-first y responsive con Flexbox y CSS Grid.
- Usa variables CSS para la paleta: negro #0a0a0a, rojo #b30000, dorado #c9a227, texto claro #eaeaea.
- Fuentes desde Google Fonts: "Cinzel Decorative" para títulos y "Inter" para el texto.
- Usa las imágenes de la carpeta `img/` (nombres exactos indicados en el prompt). Si una imagen no carga, muestra un degradado CSS como respaldo.
- Todo el contenido del sitio va en español.
- Comenta el código de forma breve y clara.
- El sitio debe funcionar abriendo `index.html` directamente, compatible con GitHub Pages.
